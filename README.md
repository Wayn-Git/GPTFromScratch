# GPT From Scratch

A repository dedicated to building and understanding Generative Pre-trained Transformer (GPT) models from scratch in PyTorch.

## Repository Structure

- **MathFoundation**: Mathematical prerequisites and activation functions.
- **BuildingANeuralNetwork**: Core neural network building blocks.
- **Attention&Transformers**: Self-attention, multi-head attention, and transformer architectures.
- **BuildGPT**: Assembly of full GPT architecture.
- **Training**: Data preprocessing, training loops, and optimization.
- **NLP**: Natural language processing utilities and tokenization.
- **Pytorch**: PyTorch specific helpers and modules.
